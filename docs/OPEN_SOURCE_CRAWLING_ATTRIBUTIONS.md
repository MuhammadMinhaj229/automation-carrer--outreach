# Open-Source Crawling Integrations

ACIOS uses adapter interfaces around independently maintained projects; it does not vendor their source code.

- Firecrawl: https://github.com/firecrawl/firecrawl — remote web extraction.
- Crawl4AI: https://github.com/unclecode/crawl4ai — browser-backed HTML/Markdown extraction.
- Browser Use: https://github.com/browser-use/browser-use — task-driven browser agent.
- Crawlee: https://github.com/apify/crawlee and https://github.com/apify/crawlee-python — crawling framework; the current adapter targets the Python package.
- Scrapy: https://github.com/scrapy/scrapy — crawling framework.
- MarkItDown: https://github.com/microsoft/markitdown — document conversion.
- Scrapling: https://github.com/D4Vinci/Scrapling — adaptive extraction.
- scrcpy: https://github.com/Genymobile/scrcpy — local Android display/control utility.
- AutoScraper: https://github.com/alirezamika/autoscraper — example-driven extraction.
- curl-impersonate: https://github.com/lwthiker/curl-impersonate — HTTP/TLS client compatibility.

This integration index is not a substitute for dependency notices. Before a release, generate an SBOM/license inventory for the exact installed versions and include the notices required by each selected dependency. GitHub stars are neither a software license nor a security review.
